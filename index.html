傳花，傳一份健康A little guide to playing

01每輪先選擇左右難度；開始前不會顯示題目或選項。Choose a level for each player every round. Questions and choices stay hidden before Start.

02主持人按「開始答題」，同時隨機揭示兩題及開始 20 秒計時。有人舉手，立即按「暫停」或空白鍵。The host presses Start to draw and reveal both questions and start the shared 20-second clock. When a hand goes up, press Pause or Space.

03先舉手的人先回答，再輪到另一位。兩人都確認後，才一起顯示結果。The first to raise a hand answers first, then the other player. Results appear only after both confirm.

04按「顯示答案」一起學習，再按「下一輪」回到難度設定。暫停後不會自動繼續計時。Use Show answers to learn together, then Next round to choose levels again. A paused clock never resumes automatically.

如未及暫停便到 0 秒，兩位本輪均不計答對。可以直接顯示答案，輕鬆再試。If time runs out before Pause, neither answer counts as correct. Reveal the answers and try another round.

題目抽完前不會重複；同輪盡量避開相同主題。重新整理會保留本機進度，各裝置獨立遊玩。沒有背景音樂。Questions do not repeat until a level’s pool is used. Similar topics are avoided when possible. Progress stays in this browser; different devices play independently. No audio is included.
